# Open CCW

一款第三方 CCW 启动器，提供账号管理、OAuth 一键登录、每日签到等功能。基于 SvelteKit 构建，部署在 Cloudflare Workers 上。

## 功能

- **多账号管理** — 支持注册多个 CCW 账号，本地加密存储 Token（PBKDF2 + AES-256-GCM）
- **OAuth SSO 登录** — 通过 CCW 官方 OAuth 授权获取 Token，无需手动复制
- **每日签到** — 登录后一键签到领取金币
- **密码登录保护** — 云端校验账号密码，登录成功后 Token 用密码派生的密钥加密存储，并记住密码用于自动恢复登录
- **设备管理** — 查看当前账号所有登录会话，支持按设备逐个登出或一键退出全部其他设备
- **消息通知中心** — 聚合「内容互动」「回复我的」等消息（开发中）
- **个人主页** — 通过 `/user/[学号或OID]` 查看任意用户的公开资料与统计

## 技术栈

| 类别 | 技术                                                                |
| ---- | ------------------------------------------------------------------- |
| 框架 | Svelte 5 + SvelteKit 3                                               |
| 样式 | TailwindCSS 4                                                       |
| 构建 | Vite 8                                                              |
| 语言 | TypeScript                                                          |
| 部署 | Cloudflare Workers                                                  |
| 加密 | Web Crypto (PBKDF2 + AES-256-GCM)、X25519 + AES-GCM（云端通信加密） |
| API  | @ccw-api (由作者本人开发的CCW 社区 API)                             |

## 使用说明

1. 访问首页，点击右上角 **login** 按钮
2. 选择已有账号并输入密码，或前往 `/register` 注册新账号
3. 注册时点击 **CCW 一键授权**，跳转到 CCW 完成授权后 Token 自动填入，仅需设置密码即可完成注册
4. 注册完成后账号以学号（uid）命名，密码用于登录与本地 Token 加密
5. 登录后，点击头部的金币图标即可每日签到
6. 点击头部齿轮图标进入 `/settings/auth` 管理登录设备，铃铛图标进入 `/notice` 查看消息通知

## 合规性说明

Open CCW 是一款**第三方**工具，与 CCW 官方无任何关联。使用本工具即表示你知晓并同意以下事项：

### 第三方声明

- 本项目非 CCW 官方产品，所有 CCW 相关服务、接口与数据版权归 CCW 官方所有
- 本项目通过 `@ccw-api` 调用 CCW 社区公开接口实现功能，不提供任何独立的在线服务

### 用户数据存储

- 账号（学号与密码）保存在云端 openccw 数据库中，用于登录时校验并换取 Token
- 用户 Token 仅保存在**本地浏览器**的 `localStorage` 中，并使用 **PBKDF2 + AES-256-GCM** 加密：密码经高迭代密钥派生后用于加解密
- 登录时会**记住密码**用于在本地解密 Token，从而在刷新页面或跳转任意页面后自动恢复登录；请妥善保管设备安全
- 本项目**服务器端不存储**任何用户 Token
- 本项目基于cloudflare worker，为改进体验，会进行后台非敏感日志上报与记录，本项目承诺对日志隐私信息进行脱敏处理，若CCW官方要求调取官方api调用记录等信息，维护者有权在未向您征求意见的情况下提供日志信息
- 密码不提供找回服务，遗忘密码后将无法登录，只能重新注册新账号

### OAuth 授权

- 通过 CCW OAuth 获取的 Token 仅用于本项目功能调用，不会用于其他用途
- OAuth 授权码在服务端解密后即返回客户端，服务端不保留任何授权记录

### 第三方服务调用

- **IP 属地查询**：设备管理功能会将登录会话的 IP 地址发送至 `ip9.com.cn` 用于属地展示
- **CCW 社区 API**：签到、消息通知、个人资料、设备管理等功能均直接调用 CCW 官方接口

### 公开资料展示

- 用户主页（`/user/[学号或OID]`）展示的资料来源于 CCW 公开 API
- 若用户不希望个人数据被展示，需在 CCW 官方调整隐私设置
